# Assignment 1 – Low Fidelity Wireframes

## Project Overview

APOD Search is a responsive web application inspired by NASA’s Astronomy Picture of the Day API. The application allows users to search astronomy images by date, view image information, and save favourite images.



## Low Fidelity Wireframes

The low-fidelity wireframes were created to focus on layout structure, spacing, and content organization before applying colours and detailed visual design.

The wireframes include:

* Mobile layout
* Desktop layout
* Tablet layout

Each layout demonstrates the placement of navigation, image sections, buttons, search areas, and favourite sections.



## Design Decisions

The wireframes were designed to create a clean and easy-to-use interface. The structure focuses on helping users quickly search and browse astronomy images.

Simple placeholder boxes and sections were used to represent:

* Navigation menus
* Search bars
* APOD image areas
* Favourite sections
* Footer content



## Layout and Responsiveness

### Mobile Layout

The mobile layout uses a single-column structure for smaller screens. This improves readability and makes navigation easier on mobile devices.

### Desktop Layout

The desktop layout uses a wider multi-section structure to display content more efficiently on large screens.

### Tablet Layout

The tablet layout balances the mobile and desktop versions while maintaining responsive spacing and organization.



## User Experience Goals

The wireframes were designed to:

* Keep the interface simple
* Make searching easy
* Organize content clearly
* Improve navigation
* Support responsive viewing across devices
